# Non-goals et feature freeze

## Feature freeze pré-soft-launch

Jusqu'à validation humaine du vertical slice, ne pas développer :

- nouveau gros système, monde, monnaie, framework UI ou architecture globale;
- nouveau mode PvP, guilde, expansion majeure de saison ou couche de progression;
- nouvelle monétisation ou activation d'achat réel avant validation du core loop;
- optimisation prématurée sans mesure;
- contenu qui contourne ou dilue l'expérience du Monde 1.

Une proposition de feature doit expliquer **quel problème joueur mesuré** elle résout. Sans problème mesuré, elle n'est pas implémentée. Vérifier d'abord le milestone actif, la nécessité pour le vertical slice, une solution plus petite et si le problème relève du contenu/polish.

Les corrections de sécurité, intégrité des données, compatibilité, accessibilité et fiabilité restent autorisées.
